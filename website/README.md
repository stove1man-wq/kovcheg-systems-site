# KOVCHEG SYSTEMS — новая корпоративная страница

Это отдельная разработка внутри `website/`. Она не заменяет и не изменяет существующий `/index.html` в корне репозитория.

## Локальный просмотр

Откройте `index.html` в браузере. Сайт не требует установки пакетов или сборки.

Для корректной загрузки изображений удобнее запустить локальный статический сервер из корня репозитория, например встроенным сервером Python:

```powershell
py -m http.server 8000
```

Затем откройте `http://localhost:8000/website/`.

## Состав

- `index.html` — семантическая структура страницы.
- `styles.css` — адаптивная визуальная система.
- `script.js` — мобильная навигация и появление блоков при прокрутке.
