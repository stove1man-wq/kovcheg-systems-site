# KOVCHEG SYSTEMS — сайт

Корпоративный сайт **KOVCHEG SYSTEMS / СИСТЕМЫ КОВЧЕГ**: https://kovcheg-systems.ru

Статический сайт на HTML, CSS и небольшом JavaScript, без сборки и внешних зависимостей. Публикуется через GitHub Pages из корня ветки `main` (домен задан файлом `CNAME`).

## Структура

```text
index.html        страница сайта
styles.css        визуальная система (палитра в переменных :root)
script.js         мобильное меню и появление блоков при прокрутке
favicon.ico       фавикон (запасной, основной — assets/brand/logo/favicon.svg)
assets/
  brand/logo/     фирменный знак: SVG, иконки, картинка для превью ссылок
  images/         изображения по разделам (см. docs/asset-catalog.md)
docs/             бренд-принципы, архитектура сайта, контент, каталог изображений
```

## Локальный просмотр

Из корня репозитория:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000/`.

## Знак бренда

Знак — корпус из двух окружностей и росток из двух листьев. Файлы и правила использования: `assets/brand/logo/` и `docs/brand-guidelines.md`.
