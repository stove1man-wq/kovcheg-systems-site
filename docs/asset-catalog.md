## Правила использования

1. Файлы в `assets/images/brand/` — исследовательские варианты. Ни один из них не является утверждённым логотипом.
2. Не использовать изображение как логотип, если в нём присутствует случайный псевдотекст или нечитабельная типографика.
3. Перед публикацией проверить разрешение, соотношение сторон, артефакты генерации, цветовой баланс и лицензионные/правовые основания.
4. Для крупных фоновых изображений подготовить оптимизированные версии WebP/AVIF после визуального отбора.
5. Текстуры применять экономно, с учётом контраста и читаемости.
6. Сохранять оригиналы; производные файлы хранить отдельно и называть по содержанию, а не по номеру генерации.
