# Каталог визуальных материалов

> Важно: каталог составлен по именам файлов и структуре репозитория. Изображения не проходили визуальную проверку в рамках этой ревизии. Поэтому здесь не назначаются точные сюжетные роли для файлов с техническими именами.

## Правила использования

1. Файлы в `assets/images/brand/` — исследовательские варианты. Ни один из них не является утверждённым логотипом.
2. Не использовать изображение как логотип, если в нём присутствует случайный псевдотекст или нечитабельная типографика.
3. Перед публикацией проверить разрешение, соотношение сторон, артефакты генерации, цветовой баланс и лицензионные/правовые основания.
4. Для крупных фоновых изображений подготовить оптимизированные версии WebP/AVIF после визуального отбора.
5. Текстуры применять экономно, с учётом контраста и читаемости.
6. Сохранять оригиналы; производные файлы хранить отдельно и называть по содержанию, а не по номеру генерации.

## Следующий этап аудита

Для каждого изображения определить:
- понятное содержательное имя;
- сюжет и подходящий раздел сайта;
- пригодность для hero / карточки / фона / текстуры;
- разрешение и соотношение сторон;
- наличие артефактов, псевдотекста и водяных знаков;
- необходимость кадрирования и оптимизации.

После визуального аудита следует заменить технические имена в веб-каталоге смысловыми именами, сохранив исходники без переименования.
